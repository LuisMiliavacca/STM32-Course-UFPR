# STM32 Microcontrollers Course - UFPR

This repository contains the scripts, lab exercises, and projects developed for the Microprocessors and Microcontrollers course in the Electrical Engineering program at the Universidade Federal do Paraná (UFPR) in Brazil.

## Overview

The source code and practical labs focus on embedded programming and hands-on experimentation with STM32 microcontrollers. Most lab assignments were implemented using a custom educational board built around an STM32 Nucleo development kit.

## Schematics & Documentation

The complete schematic for the STM32 Nucleo educational board used throughout the course is included directly in this repository for reference (readme.txt / board layout files).

## Requirements & Tools

- Hardware: STM32 Nucleo Development Board & Educational Kit
- IDE / Environment: STM32CubeIDE / Keil MDK / STM32CubeMX
- Language: C
